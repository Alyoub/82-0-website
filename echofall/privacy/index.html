Echofall Privacy Policy

Effective date: November 18, 2026

This policy describes the website version of Echofall at 82-0.studio/echofall/. It is separate from any mobile-app policy. The broader 82-0 Studio website privacy policy also applies.

In short: Echofall needs no account. The game stores expedition progress and settings in this browser. The website still sends normal network information to its host and loads Google AdSense, which may use cookies, local storage and other identifiers.

1. Information you provide

Echofall does not ask for your name, email address, phone number, precise location or a player account. If you contact 82-0 Studio by email, the studio receives the address and message you send and uses them to respond.

2. Local game save

Echofall stores one save under echofall.save.v2 in this browser's localStorage. The save can include:

  • which planets have been scanned and the current orbit or surface location;
  • collected samples, lumen cargo, scanner-upgrade and hidden-cache progress;
  • ship, surveyor and oxygen state needed to continue the expedition;
  • completed-expedition status and planet visits;
  • sound, objective-waypoint and graphics-quality settings.

The first-party game code reads and writes this save locally and contains no code that uploads it to 82-0 Studio. There is no cloud save. Clearing this site's browser data or choosing Delete save and restart in Settings removes the saved expedition.

3. Hosting and network requests

The site is deployed through GitHub Pages. Requests needed to deliver a page normally include an IP address, requested URL, browser or device information and a referrer. GitHub states that it may log visitor IP addresses for security. See the GitHub Privacy Statement.

The Echofall game loads its Three.js engine and visual assets from this website rather than a third-party JavaScript CDN. Its interface uses system fonts and does not request Google Fonts. Other 82-0 Studio pages may request Google Fonts as explained in the general policy.

4. Analytics, cookies and advertising

  • Analytics: the deployed source contains no separate analytics library or analytics account tag. Google AdSense still performs advertising delivery, fraud prevention and measurement.
  • First-party cookies: Echofall's own game code does not call the browser cookie API. It uses localStorage for the save and settings described above.
  • Google AdSense: Echofall pages load the AdSense script immediately. That request may send Google an IP address, browser or device information, the requested page, referrer and existing Google identifiers.
  • Advertising storage: depending on region, browser signals, prior choices and the site's AdSense configuration, Google and advertising partners may use cookies, local storage or other identifiers for personalized or non-personalized ads, frequency controls, reporting, security and fraud prevention.
  • Consent: this repository does not contain its own consent-management interface. Google may display a Funding Choices message configured in the AdSense account, but that account-side configuration cannot be confirmed from the website source.

Learn how Google uses information from sites that use its services, or change personalization choices in Google Ads Settings.

5. Your choices

  • Open Echofall Settings and choose Delete save and restart.
  • Clear cookies and site data for 82-0.studio in your browser.
  • Use Google Ads Settings to control personalized advertising.
  • Email ayoublayoub2006@gmail.com to ask about or delete an email you sent to the studio.

6. Children

Echofall is made for a general audience and is not directed to children under 13. The game does not knowingly ask children to submit personal information directly. Hosting and advertising providers still process requests as described above.

7. Changes and contact

This policy may change when the game or its services change. Updates will appear here with a revised effective date. Privacy questions can be sent to ayoublayoub2006@gmail.com.
